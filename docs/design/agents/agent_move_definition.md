# 移動定義 <!-- omit in toc -->

## 概要 <!-- omit in toc -->

エージェントの連続空間における移動を定義する。
移動は「向き(heading)」と「速度」によるステアリング方式とし、意思決定は知覚ベースの単純なルールとする。
学習・記憶による意思決定は v4.0.0 以降のスコープであり、意思決定部分(`decide_action()`)は差し替え可能に分離して実装する。

## 1. 移動方式

- エージェントは向き `heading`(ラジアン)を持ち、毎 tick 以下を行う。
  1. 意思決定により目標方向を決める(3章)
  2. 回頭: `heading` を目標方向へ向けて更新する。1 tick の回頭量はゲノムの `turn_speed` を上限とする
  3. 前進: `heading` 方向へゲノムの `move_speed` の距離だけ進む

```
pos.x += cos(heading) * move_speed
pos.y += sin(heading) * move_speed
```

- `move_speed`・`turn_speed`・`vision_range` は個体のゲノム値を使用する([model_definition.md](../model_definition.md) 参照)。

## 2. 知覚

- エージェントは自身を中心とする半径 `vision_range` 内の食料を知覚できる。
- 知覚できる情報は食料の位置のみとする(他エージェントの知覚は将来バージョンで検討)。

## 3. 意思決定

v1.0.0 の意思決定は次の2ルールのみ。

| 状況 | 行動 |
| --- | --- |
| 視界内に食料がある | 最も近い食料を目標方向とし、回頭して前進(追跡) |
| 視界内に食料がない | ランダムウォーク |

- **ランダムウォーク**: `heading += U(-turn_speed, +turn_speed)`(一様乱数)としてから前進する。
  - 毎 tick 完全ランダムな方向を選ぶのではなく、現在の向きを基準に揺らすことで、直進性のある探索(相関ランダムウォーク)となる。

## 4. 境界処理

- 前進の結果、座標が世界の範囲 `[0, WORLD_WIDTH] × [0, WORLD_HEIGHT]` を超える場合、座標を境界値にクランプする。
- クランプが発生した tick は、壁への張り付きを防ぐため `heading` を一様乱数で再設定する。

## 5. エネルギーコスト

- 移動コストは移動距離に比例する: `energy -= MOVE_COST_PER_UNIT × 移動距離`
- 1 tick の移動距離は `move_speed` に等しいため、速い個体ほど毎 tick のコストが大きい(速度と燃費のトレードオフ)。
- 基礎代謝(`BASE_COST`)は移動とは別に毎 tick 消費される([simulation_definition.md](../simulation_definition.md) 参照)。

## 6. パラメータ

| パラメータ | デフォルト | 説明 |
| --- | --- | --- |
| `MOVE_COST_PER_UNIT` | 1.0 | 移動距離1あたりのエネルギー消費 |

ゲノム由来の値(初期個体のデフォルト):

| ゲノム属性 | デフォルト | 説明 |
| --- | --- | --- |
| `move_speed` | 1.0 | 1 tick の移動距離 |
| `turn_speed` | 0.5 | 1 tick の最大回頭量(ラジアン) |
| `vision_range` | 5.0 | 知覚半径 |
