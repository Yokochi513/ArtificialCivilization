# 死亡定義 <!-- omit in toc -->

## 概要 <!-- omit in toc -->

エージェントが世界から除去される条件と処理を定義する。

## 目次 <!-- omit in toc -->

- [1. 死亡条件](#1-死亡条件)
- [2. 除去処理](#2-除去処理)
- [3. スコープ外](#3-スコープ外)

## 1. 死亡条件

以下のいずれかを満たした個体は死亡する。

| 死因 | 条件 |
| --- | --- |
| 餓死 | `energy <= 0` |
| 寿命 | `age >= max_age` |

- `age` は毎 tick の処理の最後に 1 加算される。
- `max_age` のデフォルトは 1000([model_definition.md](../model_definition.md) 参照)。

## 2. 除去処理

- 死亡判定は各個体の tick 内処理の最後に行い、実際の除去は tick 終了時にまとめて行う。
  - これにより、同一 tick 内の処理順によって「死亡した個体が食料を食べていた/いなかった」といった不整合が生じないようにする。
- 死因(餓死/寿命)は統計として集計する([simulation_definition.md](../simulation_definition.md) 参照)。

## 3. スコープ外

- 死骸のアイテム化・食料化は行わない(v2.0.0 以降で検討)。
- 捕食・攻撃による死亡は存在しない。
