# 繁殖定義 <!-- omit in toc -->

## 概要 <!-- omit in toc -->

エージェントの繁殖(子の生成)とゲノムの遺伝を定義する。
v1.0.0 は無性生殖とする(交配は将来バージョンで検討)。

## 1. 繁殖条件

- `energy >= REPRODUCE_THRESHOLD` を満たす個体は、その tick で子を1体生成する。
- 繁殖に意思決定は伴わない(条件を満たせば自動的に繁殖する)。

## 2. 繁殖処理

- 親のエネルギーから `REPRODUCE_COST` を減算し、それをそのまま子の初期エネルギーとする(親子でエネルギー総量が保存される)。
- 子の属性:

| 属性         | 値                                                                           |
| ------------ | ---------------------------------------------------------------------------- |
| `pos`        | 親の位置から半径 `BIRTH_RADIUS` 以内の一様乱数の位置(世界の境界内にクランプ) |
| `energy`     | `REPRODUCE_COST`                                                             |
| `max_energy` | 親と同値                                                                     |
| `age`        | 0                                                                            |
| `max_age`    | 親と同値                                                                     |
| `generation` | 親の `generation + 1`                                                        |
| `heading`    | 一様乱数                                                                     |
| ゲノム       | 親のゲノムを継承(3章)                                                        |

- 生成された子は次の tick から行動する(生成された tick には行動しない)。

## 3. 遺伝と突然変異

- 子は親のゲノムをコピーして継承する。
- コピー時、各遺伝子は確率 `MUTATION_RATE` で突然変異する。
  - 変異量: 現在値に `N(0, MUTATION_STRENGTH × 現在値)` の正規乱数を加算する(現在値の約±10%程度の揺らぎ)。
  - 変異後の値は遺伝子ごとの許容範囲にクランプする。

| ゲノム属性     | 許容範囲     |
| -------------- | ------------ |
| `move_speed`   | 0.1 〜 3.0   |
| `turn_speed`   | 0.05 〜 3.14 |
| `vision_range` | 1.0 〜 20.0  |
| `arm_length`   | 0.1 〜 2.0   |

- `MUTATION_RATE = 0` とすれば突然変異を無効化できる(デバッグ・比較実験用)。
- 世代を重ねることで、環境(食料密度・移動コスト)に適したゲノムへの淘汰が起きることを観察対象とする。

## 4. パラメータ

| パラメータ | デフォルト | 説明 |
| --- | --- | --- |
| `REPRODUCE_THRESHOLD` | 150.0 | 繁殖可能となるエネルギー閾値 |
| `REPRODUCE_COST` | 75.0 | 繁殖時に親が子へ渡すエネルギー |
| `BIRTH_RADIUS` | 1.0 | 子の出生位置の親からの最大距離 |
| `MUTATION_RATE` | 0.1 | 遺伝子1つあたりの突然変異確率 |
| `MUTATION_STRENGTH` | 0.1 | 突然変異の標準偏差(現在値に対する比率) |
