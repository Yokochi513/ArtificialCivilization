# 食事定義 <!-- omit in toc -->

## 概要 <!-- omit in toc -->

エージェントが食料を摂取しエネルギーを回復する仕組みを定義する。

## 目次 <!-- omit in toc -->

- [1. 摂取条件](#1-摂取条件)
- [2. 摂取処理](#2-摂取処理)
- [3. 競合](#3-競合)

## 1. 摂取条件

- 移動処理の後、自身からの距離がゲノムの `arm_length` 以内にある食料を摂取できる。
- 範囲内に複数の食料がある場合、最も近い1個のみを摂取する(1 tick に食べられるのは1個まで)。

## 2. 摂取処理

- エネルギーを回復する。`max_energy` を超えた分は切り捨てられる。

```
energy = min(energy + food.energy, max_energy)
```

- 摂取された食料は世界から除去される。
- 摂取は意思決定を伴わない(条件を満たせば自動的に食べる)。

## 3. 競合

- 同じ食料を複数のエージェントが摂取可能な位置にいる場合、その tick の行動順が早い個体が摂取する(早い者勝ち)。
- 行動順は毎 tick シャッフルされるため、特定個体が恒常的に有利になることはない([simulation_definition.md](../simulation_definition.md) 参照)。

## パラメータ <!-- omit in toc -->

ゲノム由来の値(初期個体のデフォルト):

| ゲノム属性 | デフォルト | 説明 |
| --- | --- | --- |
| `arm_length` | 0.5 | 食料を摂取できる距離(腕の長さ) |
