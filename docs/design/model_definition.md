# model定義 <!-- omit in toc -->

## 概要 <!-- omit in toc -->

本アプリ内で使用するモデルの型を定義する。

## 目次 <!-- omit in toc -->

- [1. エージェント](#1-エージェント)
- [2. 食料](#2-食料)
- [3. ゲノム(Genome)](#3-ゲノムgenome)


## 1. エージェント

| 属性       | 型         | 説明                       |
| ---------- | ---------- | -------------------------- |
| id         | u64        | 一意な識別子(連番)         |
| pos        | (f32, f32) | 現在位置                   |
| heading    | f32        | 向き(ラジアン)             |
| energy     | f32        | 現在のエネルギー           |
| max_energy | f32        | 最大エネルギー             |
| age        | u32        | 年齢(ステップ数)           |
| max_age    | u32        | 寿命年齢(default1000)      |
| generation | u32        | (可視化用)世代             |
| genome     | Genome     | 遺伝形質([3. ゲノム](#3-ゲノムgenome)) |


## 2. 食料

| 属性   | 型         | 説明               |
| ------ | ---------- | ------------------ |
| id     | u64        | 一意な識別子(連番) |
| pos    | (f32, f32) | 現在位置           |
| energy | f32        | エネルギー回復量 |

## 3. ゲノム(Genome)

| 属性         | 型  | 説明                   |
| ------------ | --- | ---------------------- |
| move_speed   | f32 | エージェントの移動速度 |
| turn_speed   | f32 | エージェントの回転速度 |
| vision_range | f32 | エージェントの視界     |
| arm_length   | f32 | エージェントの腕の長さ |
